# Customer Churn Prediction using Machine Learning

## Project Overview
This project focuses on predicting customer churn for a telecom company using Machine Learning techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- SHAP
- Matplotlib
- Seaborn

## Machine Learning Models
- Logistic Regression
- Random Forest
- XGBoost
- Tuned XGBoost

## Project Steps
- Data Loading and Exploration
- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- Data Preprocessing
- Model Training
- Model Evaluation
- Cross-Validation
- Hyperparameter Tuning
- SHAP Model Interpretation

## Evaluation Metrics
- Precision
- Recall
- AUC-ROC
- Cross-Validation

## Dataset
The project uses a telecom customer churn dataset containing customer information, services, account details, and churn status.

## Key Insights
The analysis identified important factors associated with customer churn, including contract type, tenure, online security, technical support, internet service, payment method, and monthly charges.
